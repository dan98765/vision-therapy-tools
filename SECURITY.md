# Security Policy

These are static, client-side pages. They have no backend, accounts, tracking or network requests, and they store nothing. Each page ships with a Content-Security-Policy that blocks all network access.

## Reporting a vulnerability

Please report problems privately through GitHub: go to the **Security** tab of this repo and choose **Report a vulnerability**. Please do not open a public issue for a security problem.

This is a personal project maintained on a best-effort basis, so there is no guaranteed response time, but reports are welcome and will be looked at.

## Scope

In scope: anything that could cause a page to run unexpected code, make network requests, or expose user data.

Out of scope: clinical or medical concerns. These tools are not medical advice; use exercises as directed by your vision therapist.
